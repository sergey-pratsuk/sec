# Система контроля КПП (Въезд спецтехники и материалов)

On-Premise решение на базе **Laravel 11** и **Livewire 3** для фиксации въезда грузового транспорта, спецтехники и строительных материалов на территорию строительной площадки. Оптимизировано под мобильные устройства охранников КПП.

## Функционал
*   **Регистрация въезда**: ввод госномера, выбор материала из динамического справочника, указание объема или веса.
*   **Тройная фотофиксация**: обязательное добавление трех снимков (Общий вид ТС с госномером, Содержимое кузова/груз, ТТН/Накладная).
*   **Прямой вызов камеры**: на мобильных устройствах формы загрузки файлов принудительно открывают заднюю камеру смартфона, минуя галерею.
*   **Панель диспетчера (`/admin`)**: интерактивный журнал всех заездов в реальном времени с выводом фотографий в модальном окне.
*   **Безопасное хранение медиа**: файлы хранятся локально в закрытом периметре сервера (`storage/app/private/`) и отдаются диспетчеру через защищенный внутренний маршрут после проверки прав.

## Стек технологий
*   **Backend / Frontend**: PHP 8.3 + Laravel 11 (Monolith)
*   **Реактивный UI**: Livewire 3 + Alpine.js
*   **Стилизация**: Tailwind CSS (сборка через Vite)
*   **База данных**: MariaDB

## Схема базы данных (MariaDB)
*   `materials` — справочник строительных грузов (наименование, единица измерения).
*   `checkin_logs` — журнал регистраций (госномер, ID материала, объем, ID оператора, штамп времени).
*   `checkin_photos` — полиморфная связь для путей к файлам (тип фото: `vehicle`, `cargo`, `invoice`; локальный путь).

## Локальное развертывание

### 1. Требования к окружению
*   PHP 8.2+ (с расширениями `pdo_mysql`, `gd`, `mbstring`, `curl`)
*   Composer
*   Node.js 22+ & NPM
*   MariaDB Сервер

### 2. Настройка проекта
Клонируйте репозиторий, перейдите в папку проекта и установите зависимости:
```bash
composer install
npm install
```

### 3. Конфигурация окружения
Создайте локальный файл `.env`:
```bash
cp .env.example .env
php artisan key:generate
```
Отредактируйте параметры подключения к MariaDB в файле `.env`:
```env
DB_CONNECTION=mariadb
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=construction_db
DB_USERNAME=sail
DB_PASSWORD=password
```

### 4. Миграции и тестовые данные
Создайте базу данных `construction_db` в MariaDB, затем выполните накат таблиц и запуск сидера для наполнения справочника материалов и создания учетной записи охраны:
```bash
php artisan migrate:fresh --seed
```

### 5. Запуск в режиме разработки
Запустите сервер компиляции стилей Vite в первом окне терминала:
```bash
npm run dev
```
Запустите встроенный веб-сервер Laravel во втором окне терминала:
```bash
php artisan serve
```
Приложение будет доступно по адресу: `http://127.0.0.1:8000`
Панель диспетчера доступна по адресу: `http://127.0.0`
